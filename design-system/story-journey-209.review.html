The harbour

The last ferry had gone. Along the harbour wall, lamps came on one by one, laying narrow paths of gold across the water.

“Someone was here before us.” Maren held the folded chart to the light. The ink had run at the edges, but the marks beneath the bridge were clear.

A bell sounded beyond the breakwater. Maren turned towards it, drawing her coat close as the wind lifted from the sea.

Proposed behavior and boundaries

Proposed, not approved or implemented. Turn 209 connects proposed turns 206–208 after the owner asked how the pages are reached from Story. It does not approve those turns or change application UI. Review figures, people, timings and prices are illustrative public fixtures. Companion branches are PRs 1685, 1686 and 1687; their proposal rules remain in force.

1 · Existing navigation first. Story → Chapters → the chosen chapter → Audiobook. Chapter entry respects the remembered view and keeps the visible Manuscript / Audiobook / Timing switch. The book-level Audiobook door remains reachable in the existing rail and retains turn 199. No new dashboard, wizard or compulsory sequence is introduced.

2 · Discoverable chapter actions. At desktop widths reserve a labelled Direct and illustrate menu containing Direct this chapter, Illustrate this chapter and Looks, with their actual state. Add one quiet Export… press beside it. At narrow widths use the visible label Chapter actions, grouping the three under Direct and illustrate, then Export separated below; other folded controls retain their existing order. This deliberately extends turn 194/203 toolbar rules and turn 208 rule 12, which had introduced no new toolbar action. Read and Listen keep the established responsive placement, held below the list when the toolbar is narrow.

3 · Chapter Looks is an overview. One row per character shows identity, number of saved looks and the named chosen look with thumbnail. The chosen row opens turn 207’s collection. Main photo is explicit when no costume is chosen. New look remains available without widening a phone row. Use for Chapter N commits and returns to Looks; Done closes Looks. Browsing never commits. Changing a chapter look affects future generation; existing pictures and picture-only overrides stay unchanged (SPEC-047 R-112/R-114/R-146). Do not infer outfit identity from these illustrative portrait stand-ins.

4 · One return context. Every sheet carries the chapter id, originating control, view, selected block and list scroll. Closing restores that context and focus. Nested flows replace the visible sheet rather than stack active modals. The caller matters: Looks opened from Illustrate returns to that draft; a saved-look collection opened from New look returns to its unsaved clothing/name/candidates. A successful Use returns to chapter Looks. Escape matches Cancel/Back and never accepts a draft. Deleting or changing an origin shows a plain recovery to the surviving chapter; no stale write.

5 · Reading remains explicit. Read opens the existing scoped quote review, including remaining/changed blocks when relevant, and a single explicit confirmation starts work. Turn 206 owns one chapter run, its estimate, truthful preparation state and Activity notification. Returning to a chapter does not start, stop or repeat work. Stop requires the actual current run; listening is offered only when current audio is playable. These fixtures show alternate states, not a mandatory read before every edit.

6 · Optional motion belongs to Picture. Select a pictured passage → Picture → Animate → quote → generate → preview → Use clip. This is turn 208’s flow, with the chapter retained as the return destination. A completed candidate does not attach itself. Keep still returns unchanged; Use clip applies to that picture only and retains its original still. No toolbar-level Animate button. A source changed during generation cannot silently receive the old result.

7 · Chapter entry selects a scope. Export… in a chapter opens the same export sheet as the book door with Include = This chapter and the exact current chapter shown. Entry at the book door defaults to Whole book. The author may deliberately change scope. This is a new proposal: the current exporter does not yet support chapter scoping. The chosen scope must reach both supported player/video export plans and receipts, not merely filter the UI. Switching format preserves scope; reopening through an entry uses that entry’s explicit default rather than an old book choice.

8 · Scope is not file partitioning. Include chooses chapters. Files chooses One a chapter / One for the book only inside Whole book video export. This chapter makes one video or a one-chapter player package. Name included chapters and omissions before confirming; do not silently promote This chapter to Whole book or export a different ready chapter. When the current chapter is incomplete, show its missing/stale/flagged requirement and a scoped Read or Review return, disable export, and retain export settings through the recovery. Read remaining blocks opens a quote for those blocks, not the illustrative full-chapter quote.

9 · Export readiness is format-specific. Missing audio that the export plan requires blocks export. Missing measured word timings only disables Highlight current word; plain subtitles remain available. Timing preparation has its own capability/processing/quote review and correctly named Activity record. No automatic provider work, downloads or invented timestamps; turn 208 owns exact-audio/text alignment. Switching scope recomputes every readiness check and size/time estimate. Do not label guessed duration or cost as measured.

10 · Background work and results. Closing a sheet never cancels a read, animation or export. Activity provides its durable return path. Export progress and completed-file Open / Show in folder stay in the same scoped export record; stopping and retrying preserve existing journal/idempotence rules. Listen opens the existing shared player from the chapter and closes back there with playback place retained (SPEC-047 R-66/R-71). Never navigate to a different chapter because a background job completed.

11 · Phone, keyboard and zoom. Sheets use one active modal, focus trap and reserved footer. Restore focus to the actual opener, including a chapter row reached via navigation. Menus support arrows/Home/End, Escape and outside dismissal without writes. Touch controls are at least 44 px. At 390/320 px and 200% text scale the sheet body scrolls; titles/actions remain reachable and the document has no horizontal overflow. The static phone frames draw the placement; runtime focus, 320 px and zoom remain implementation acceptance checks.

12 · Bounded implementation after approval. Amend SPEC-047 for explicit chapter export scope and toolbar/return rules in the same implementation session. Keep shared export selection in contracts and coordinator plans; client filtering alone cannot enforce scope. Test both formats, both entries, route changes, chapter removal, incomplete audio, stale timing, model absence, generation rejection, interrupted jobs and re-entry preserving drafts/selection. Rebase 206–209 master additions together without dropping older turns. No implementation or merge is authorized by this proposed design artifact.
