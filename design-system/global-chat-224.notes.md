## Corrections and verification

Studio’s generic canvas button rule had overridden composer controls. The existing source
now excludes those controls. A grid overlay lets wrapped placeholders reserve height above
the toolbar; the toolbar grows for phone controls. Compact tools retain minimum chip sizes,
hide repeated agent copy, collapse Read replies to its named speaker and wrap when necessary.
Touch Attach no longer hangs outside its box. Tool rows reserve at least 8px above and
below their controls; icon-only controls have zero padding and centre on both axes. Existing single-line World/canon hints retain
their absolute positioning. The source changes fix the existing composer, not the new Chat host.

The design fixture separately preserves the body-portalled phone composer, reserves its
measured height, and retains its conversation after typing rerenders the existing Studio.
These prototype mechanics are not the future application’s presentation/authority owner.

Three gates:

1. Original/restoration commit hashes, seven frames, eleven rules, original styles and all
   other-turn preservation.
2. Matching GPT-5.4 / High specimens and ten rendered master comparisons: chip, mark,
   effort, popover, search, row, footer, details card, effort menu and fixed World label.
   The matching touch specimen has enough space for the full chips; narrow rows use the
   existing compact effort treatment, starting earlier for 44px touch controls.
   A named World control has no picker/mark/effort; its proposed host hides an absent name.
3. Whole-page empty and multiline drafts, clipping, overlap, 8px tool-row margins, icon centring and actual centre hit tests at
   1440/1280/1100/1099/984/600/599/390/320 with mouse, and 984/599/390/320 with touch.
   Picker bounds and desktop/phone modes are checked. A negative control recreates the supplied
   desktop screenshot’s original CSS and must fail the geometry gate before the fixed view passes.
