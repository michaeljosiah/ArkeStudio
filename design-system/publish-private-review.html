New edition

Scope and status. This is a proposed design turn for private story publishing, awaiting author review. It is not an implementation or an approval record. EPUB and M4B are the first delivery pair. A narrated EPUB, a new mobile reader, access-controlled hosting, store release and automatic Kindle/Audible synchronization are outside this turn.

One entry, existing owners. Publish opens from the story, audiobook and Publications with the same production identity. It adds a publication task, not a second manuscript or audiobook editor. Keep ordinary Word, video and existing player exports available. Existing video-v1 publications and web packages remain visible under Other exports / Open publication; never relabel them as new story editions without an explicit import.

Edition identity. Title, author/pen name, language, optional cover and description, edition label, selected chapters and outputs belong to the edition setup. Defaults come from the story; editing these fields does not rename or rewrite it. One immutable edition groups the chosen outputs. A new edition gets a new identity even if its label matches an older one; a copied file keeps its original identity.

Selection is deliberate. Initial scope is Whole story. The selected-chapters fixture shows an author-chosen excerpt of six out of eight. Preserve manuscript order; do not offer another ordering authority. Every selected chapter must exist and contain prose. Planned chapters are shown with a reason. No silent omission is allowed: the author must explicitly change scope or deselect a chapter. Ebook-only output does not require narration.

Narration is Arke’s. Audiobook output consumes current chosen takes, reading choice, direction and the existing resolved listening/mix plan. Preserve its pauses, reactions, beds and other prepared sound. Do not concatenate takes again when a chapter mix owns timing. Do not synthesize, replace with device text-to-speech, or charge a provider during publishing. Open audiobook navigates to the precise chapter and problem, preserving the publication draft and return location; generation stays in its existing quoted workflow.

Readiness. A selected audio chapter with missing, stale, flagged, unreadable, uncleared or unsupported media blocks audio creation and names the chapter and cause. Apply the existing rights and release gates. Explain missing local encoding tools with a named action. Never advertise a complete book when only complete chapters happened to survive. Book-only is an explicit changed choice. Optional missing cover is allowed; a chosen missing cover blocks until replaced or removed.

Preview and capture. Preview renders the candidate EPUB and samples the exact chosen audio plan; it does not merely restyle the live manuscript. Validate navigation, text, media, durations and the format before Create edition. Source changes invalidate the preview and retain choices (224m). The Create press validates and captures one coherent set of text, assets, mix, settings and compiler identities for every output. Subsequent story edits cannot change that edition. Use the existing capture and publisher services, extended by profile, rather than treating the current exports as already durable publication builds.

Local creation and recovery. Create edition writes private files on the host. Desktop uses a folder picker; a remote author’s phone uses the trusted desktop and downloads completed outputs. Track preparing, creating, checking, ready, failed and cancelled per job and output. Ready for the edition means every requested output is verified and durably completed. Preserve verified work after a partial failure and retry the same captured edition. Reconcile uncertain completion before reporting failure or cancellation. Choosing a different destination is an explicit recovered copy/new delivery, not mutation of an existing completion receipt.

Book and audio formats. The first slice upgrades the existing reflowable EPUB exporter with cover, author, language, contents, chapter titles and accessible text. It adds one AAC M4B with chapter markers from the selected titles and shared edition metadata, plus optional MP3/WAV chapters through SPEC-047’s exporter. Default private audio is As produced; do not silently apply retail normalization or additional gaps. Confirm encoding and extension compatibility in named mobile consumers. Retail settings remain a separately specified later target.

Private delivery. The final page offers standard files individually and a folder containing them. It never requires the recipient to install Arke or obtain the source world. Exclude prompts, rejected takes, character reference material, source paths and credentials; include only deliberately published prose, cover and required output assets. Download or Show files is not a sent receipt. Opening a share surface is not proof that a recipient received it. Copied private files cannot be recalled, so do not draw a revoke control.

Kindle handoff. Read on Kindle saves the EPUB and opens Amazon’s HTTPS Send to Kindle page in the user’s browser. The user performs Amazon login and upload there; Arke neither handles Amazon credentials nor sends email automatically. The page explains that Amazon receives the file. Until an actual supported integration can verify delivery, retain Files created / handoff opened, never Sent to Kindle. The EPUB contains text and images, not a promised playable Arke soundtrack.

Listening handoff. Download M4B is always offered after success. Open in… uses a supported native share/open surface only where available; otherwise show import instructions and Download. An external audiobook app must support local files, chapter navigation, resume, seeking and background/lock-screen playback. Test iOS and Android consumers before advertising compatibility. Kindle and a separate audiobook app have independent positions. The Arke player remains an optional existing export, with phone file handling/offline/background behavior explicitly tested before claiming support.

Library and later edits. Publications groups immutable editions by work, with outputs, date, chapter scope and local availability. Open, preview and copy completed editions without the source world or providers. A changed source offers New edition and leaves earlier editions intact. Missing local files show Locate files or Create new edition; never regenerate different bytes under an old identity. Existing resume data stays outside immutable output, and a new edition does not inherit incompatible positions.

Desktop, Fold and phone. Reuse the existing PageSheet behavior: focus containment, Escape/Close, scrollable body, preserved draft and return focus. At phone widths use a full-page sheet, one column, 44px minimum touch targets and a visible footer above safe areas and the keyboard. Fold uses a single responsive task; do not introduce a second editing pane. Counts and statuses must use text as well as colour. Progress announcements are polite; actionable failures use an alert. Labels are programmatic; chapter selection and all actions are keyboard reachable. The fixtures draw paused playback and never start sound automatically.

Acceptance and evidence. Before shipping, run EPUBCheck and inspect the same sample in Kindle on iOS and Android after Send to Kindle. Verify author, cover where supported, navigation, Unicode, emphasis and chapter scope after Amazon conversion. Verify the M4B and MP3 outputs in named file-importing players: exact character voices and mix, chapter boundaries, duration, seek, resume, offline and background playback. Exercise source-change races, incomplete narration, disk-full, cancellation, retry, missing output and a remote author’s download. No format conformance check substitutes for the phone tests.

Design lineage and first slice. This turn extends SPEC-012 R-49/R-52, SPEC-047 R-22–R-28/R-72 and SPEC-048 R-4/R-6–R-18/R-24–R-25. SPEC-048 book/audio profiles remain proposed; record their interoperability decision before implementing them. SPEC-025 R-17–R-19 separates local completion from an external release. Implement common edition capture/history, polished EPUB and chaptered M4B plus the private handoffs first; optional chapter files and the existing player adapter follow without blocking the initial complete reading/listening path. No application behavior or private capability spec is amended by this review draft.

External evidence checked 13 October 2026: Send to Kindle; Kindle Assistive Reader; Read & Listen. These do not establish a private EPUB + Arke-audio import into Kindle.
