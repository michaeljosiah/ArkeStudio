# Research

This folder holds research that informs how Arke's agents behave and how its screens are designed.
Each note says when it was gathered, how strong each piece of evidence is, and where it came from,
so a later reader can check it rather than trust it.

A note here is input to a decision, not the decision itself. The decision lives in a design turn
in the design master or in a spec in the private specification set, and cites the note it used.

## How a note is written

- **Gathered** is the date of the searches, since trade figures change quickly.
- Each claim that leans on a number or a named source carries its link.
- **Evidence strength** is said plainly. A trade report is not a study, a vendor's guide is not a
  practitioner's account, and a search excerpt is not a page that was read.
- Quotations are kept to a minimum. Paraphrase is attributed.
