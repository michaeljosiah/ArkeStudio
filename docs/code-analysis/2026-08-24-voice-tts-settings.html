Executive Summary

The intended provider split is good, but the local cloned-voice lane is not shippable end to end.

Arke has three additive speech paths, not a migration from one to another: Voxa hosts Kokoro preset TTS and Whisper dictation; ComfyUI hosts an IndexTTS recipe for voices cloned from a reference recording; ElevenLabs is the metered cloud TTS path. This is a coherent architecture. It keeps cloud spend in the durable queue, leaves small local inference in a supervised minimal sidecar, and reuses the existing recipe/VRAM machinery for a model too large and Python-heavy for Voxa.

The implementation currently breaks that contract at several integration seams. A ComfyUI voice can be shown but not assigned through the normal handler, production and Bench generation omit its required speaker clip, and successful FLAC output is rejected by the global ComfyUI sanitizer. Those are independent blockers. The same lane also has an unconfined clip path that can read and upload a file outside the world, and its custom node and 10.2 GB model download are not actually verified.

Settings has the right top-level separation, but several controls overstate what they govern. The global Voice routing default is not consumed by any voice execution path. Voxa repair and model-completion restart use component IDs that do not exist. The narrator picker can persist ComfyUI while read-aloud rejects it. A typed ComfyUI URL may be remote while voice rows still say "on this machine." These gaps make Settings a partly descriptive view rather than an authoritative configuration surface.

Shipping assessment: Kokoro and ElevenLabs have credible core paths, subject to the reliability and security findings below. Local cloned voice should remain unavailable in release UI until VTS-01, VTS-02, VTS-04, and VTS-06 are resolved and covered by one real end-to-end test. The unauthenticated loopback transport is a broader desktop security blocker because it exposes all of these settings and dispatch commands.

Architecture & Configuration Trace

Voxa / Kokoro / Whisper
Settings chooses a host-owned executable or bundled runtime. Electron launches it on loopback with fixed model and espeak paths, no shell, and a minimal environment. Kokoro previews and narration call /tts directly; Bench/production takes can use the queue adapter. Dictation calls /stt.
ComfyUI / IndexTTS
Settings chooses a local install, managed install, or URL and optionally maps its models folder. A world-level cloned-voice record maps {provider: "comfyui", voiceId} to a source clip. The fixed recipe uploads that clip, submits a graph, polls, and should land an unmetered take through the ordinary queue.
ElevenLabs
Settings stores an encrypted key and exposes one voice-tts manifest model. Catalogue listing is direct and free. Preview, narration, Bench, and dialogue synthesis enter the job queue for estimate, ledger, artifact landing, and finalization.
Settings persistence
settings.json stores routing, model switches, narrator, Voxa, and ComfyUI configuration. credentials.dat stores OS-encrypted provider keys. World voice assignments live on sheets; cloned voices and clips live under each world.

Detailed Findings

CRITICALCERTAIN ComfyUI cloned speech is rejected after generation

packages/providers/src/comfyui/recipes.ts:377-379; packages/coordinator/src/comfyui/sanitize.ts:248-263; packages/coordinator/src/world/provider.ts:467-479

Dimension: Bad TypeScript/Node practices (cross-layer correctness).

Evidence:

"5": { class_type: "SaveAudio", inputs: { audio: ["4", 0], filename_prefix: "arke_voice" } }

if (startsWith(data, PNG_SIGNATURE)) return sanitizePng(data);
if (... === "WEBP") return sanitizeWebp(data);
if (... === "ftyp") return sanitizeMp4(data);
return { ok: false, reason: `... container the sanitiser does not handle ...` };

MEDIA_TYPES includes .mp3 and .wav, but not .flac.

Why it matters: The recipe and provider client agree that SaveAudio produces FLAC, but every ComfyUI artifact passes through an image/video-only sanitizer. A successful, potentially minute-long generation is converted to a failed job. Even bypassing the sanitizer would leave the file unservable and only non-empty-body verified. This independently blocks previews, Bench takes, and production takes.

Recommendation: Pick one supported container end to end. The smallest coherent change is to emit WAV, add a WAV metadata sanitizer, use strict RIFF/WAVE verification, and retain existing media serving. If FLAC is retained, add FLAC sanitization, signature/stream verification, MIME serving, and cache-hit validation together.

Effort: Moderate.

CRITICALCERTAIN Cloned-voice clip paths can escape the world and are exposed durably

packages/contracts/src/voice.ts:155-170; packages/coordinator/src/voice/library.ts:230-237; packages/coordinator/src/voice/service.ts:460-474; apps/desktop/src/main.ts:602-607

Dimension: Bad TypeScript/Node practices (path security and leaky state).

Evidence:

clip: z.string().min(1)

const absolute = join(store.dir, fromPortable(voice.clip));
await stat(toExtendedLength(absolute));
return absolute;

Why it matters: A plain world is user-editable/importable. A clip such as ../../sensitive.wav, an absolute path, or a symlink can resolve outside the world. Previewing that voice reads the host file and uploads it to the configured ComfyUI, which may be remote. Valid clips also put the absolute world path into job params, the queue journal, snapshots, and renderer events, weakening portability and host-path isolation.

Recommendation: Store only a validated portable path or voice ID. Pass verified bytes ephemerally and never journal the resolved absolute path.

Effort: Moderate.

CRITICALLIKELY The privileged loopback transport has no authentication

packages/coordinator/src/transport.ts:78-175; packages/contracts/src/frames.ts:748-888

Dimension: Business-logic placement and boundary security.

Evidence:

res.setHeader("Access-Control-Allow-Origin", "*");
const wss = new WebSocketServer({ server });
wss.on("connection", (socket) => this.accept(socket));

Why it matters: Knowledge of the random loopback port is the only capability check. A local process, or a hostile browser origin able to find the port, can request the complete snapshot and send schema-valid settings, credential, voice clone, and paid-dispatch commands. MAJORCERTAIN Paid ElevenLabs audio is not crash-durable

Dimension: Bad TypeScript/Node practices (lifetime and recovery correctness).

Evidence:

Why it matters: SPEC-022 explicitly leaves ElevenLabs cloning unbuilt, but provider probes and rows still advertise it. The visible clone action always creates a local ComfyUI library entry; no queue-backed ElevenLabs clone client exists.

Recommendation: Until a cloud clone operation exists, stop declaring voice-clone available and set catalogue rows canClone: false, or render a disabled provider-specific action with the reason.

Effort: Trivial.

Confirmed-Intentional

  • ComfyUI is additive, not a transition away from Voxa. SPEC-021 states that Voxa continues to cover preset speech while ComfyUI adds voice-tts recipes whose identity is a reference clip (docs/specifications/021.local-image-and-video-generation.md:63-74). This audit does not recommend consolidating those runtimes.
  • Local previews and paid cloud speech route differently on purpose. Kokoro audition/read-aloud may call Voxa directly at zero cost, while cloud previews and generated takes use the queue for cost, reconciliation, and landing (docs/specifications/011.voice.md:140-153).
  • Remote/user-directed ComfyUI is supported. SPEC-021 permits any reachable URL. VTS-08 is about accurately classifying voice data and obtaining informed consent, not banning remote image/video engines.
  • Host-owned file selection is a real security seam. Voxa, ComfyUI, and clone-file paths originate from Electron dialogs or host discovery, not renderer-provided path strings (packages/contracts/src/frames.ts:844-864).
  • The cloned library is world-level. The sheet link is provenance, not ownership; a voice can be reused across characters. The library entry is written after the clip so the picker cannot expose a half-created voice (packages/coordinator/src/voice/library.ts:10-26,152-198).
  • Keeping a voice-owned clip in addition to the artifact is deliberate. The implementation chooses resilience when an artifact is removed. This differs from an older SPEC-022 sentence and should be reconciled in documentation, but the duplication itself is not reported as waste.
  • Cloud cloning remains deferred. SPEC-022 explicitly leaves the ElevenLabs clone route out of scope (docs/specifications/022.local-cloned-voice.md:48-54). VTS-18 asks only that the current UI stop claiming it is available.
  • The provider/queue abstractions are justified. They isolate credentials, paid reconciliation, local-zero ledger behavior, host file reads, fixed recipes, and test doubles. No speculative interface finding was identified.
