World Chat works on the local model. An answer the model wraps in a code block or a line of
explanation is now read rather than refused. Try again asks for your default model again, so a
model you chose in Settings after a failure is the one it uses. When an answer can't be used, the
chat says so plainly, and a choice that belongs in Settings names the agent and opens Harness.

On a Fold or a tablet the keyboard no longer covers the conversation. The page shrinks to what is
left above it, and while you type the world's tabs step aside. A canon thread opens on the
conversation with its message box held at the foot, and the entry it is about opens to four lines
with Show all.

Settings is sized for fingers: model menus, the harness list, key fields and Measure are 44 pixels
tall. On a character's page, read-aloud and copy sit under the text instead of over it. In the Cut,
a vertical production's picture keeps to its place on a Fold and a phone, so the lanes and the
Library are back. Activity names shots by number and title.

Arke is also told every action it can prepare, so World Chat can reach imports, kits, props,
voices and productions, not only the world's metadata and canon. The AI models page shows a poster
from each image and video model. The first adapter dispatch after launch measures the machine
itself instead of refusing, and adult adapters no longer wait on a compliance assessment.
