Arke Studio opens directly on the loading screen now. The choice between running locally and
the cloud that is not built yet, and the extra click to launch, are both gone; starting the app
is starting the app.

And a production embedding the engine can now ask it for a chapter's page illustration and its
narration, not only the prose and the portraits it could already make. Each request keeps its
own output, survives a restart mid-flight, and can be cancelled from the host's own queue; consent,
safety review and billing stay the host's to decide.
