# Skyharbour storm protocol

This is fictional sample material for the voice audition.

Skyharbour's storm mooring code is AMBER-17. It identifies the amber ring on the
lower dock, not a passenger gate. When a red storm warning sounds, incoming ships
must attach three anchor chains to that ring and lower every sail canopy.
Passengers wait inside the copper-roofed shelter until the harbour keeper gives
the all-clear. The eastern passenger bridge remains closed during red warnings.
